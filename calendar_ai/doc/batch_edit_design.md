# 批次行程修改 (Batch / Multi-Event Edit) 與多重選取方案設計說明書

本文件針對使用者提出之「一次修改多個行程」與「靈活的多重選取機制 (Multi-Selection Methods)」進行全面的 UI/UX 互動模式、選取策略、表單動態轉換與 API 復原機制規劃。

---

## 🎯 需求場景與目標

使用者在管理行程時，常有以下多行程選取與批次修改需求：
1. **跨時間/跨日期多選**：在週檢視或月檢視中，自由挑選不連續的多個行程進行統一設定。
2. **行動裝置無 Ctrl 鍵的多選**：在手機平板上流暢進行多行程複選。
3. **同類行程快速連鎖選取**：一鍵選取所有相同類型、相同顏色或相同關鍵字標題的行程。
4. **時段與整天/整週批量選取**：一鍵勾選某一整天、整週或特定時間區段（如 09:00~12:00）內的所有行程。
5. **批次變更與復原**：批次修改顏色、類型、標題、時間平移順延或刪除，並支援 `Ctrl + Z` 一鍵復原。

---

## 🛠️ 多重選取 (Multi-Selection) 完整方案陣列

為滿足不同情境與裝置（桌機/手機），系統規劃以下 **8 種多重選取方案**：

```
                              ┌── 1. Ctrl / Shift + 點擊 (桌機直覺)
                              ├── 2. 「☑ 多選模式」開關 Toggle (跨平台)
                              ├── 3. 滑鼠拖曳矩形框選 Lasso (時段圈選)
  多重選取方案 (Selection Methods) ┼── 4. 行動裝置長按 (Long-Press 500ms 觸控)
                              ├── 5. 智慧同類/同名連鎖選取 (Smart Select)
                              ├── 6. 日期/週欄標頭「全選當天/當週」 (Header Select)
                              ├── 7. 時間範圍拉條選取 (Time-Range Slider)
                              └── 8. 獨立清單視圖與核取框 Drawer (Batch List View)
```

---

### 方案一：Ctrl / Shift 點擊複選 (桌機專用)
- **操作**：按住 `Ctrl` (Windows) 或 `Cmd` (Mac) 點擊行程卡片，即可自由選取/取消選取多個行程。若按住 `Shift` 點擊兩張卡片，可直接選取兩者之間的所有行程。
- **視覺**：卡片邊框呈現高亮藍光與右上角 `☑` 選取標籤。

### 方案二：「☑ 多選模式」切換開關 (跨平台)
- **操作**：在表單上方提供「☑ 開啟多選模式」切換開關。
- **特點**：開啟後，滑鼠或手指直接點擊任何行程卡片皆自動**累加選取**，無需按住鍵盤修飾鍵，對手機與平板體驗極佳。

### 方案三：滑鼠矩形拖曳框選 (Lasso / Box Select)
- **操作**：在日曆時間軸區域按住滑鼠左鍵並拖曳，畫面出現半透明藍色框選矩形 (`.selection-box`)。
- **特點**：凡落在矩形覆蓋範圍內的行程全數自動切換為選取狀態，適合快速選取連續幾天或特定時間區段的行程。

### 方案四：手機/觸控長按觸發 (Long-Press 500ms)
- **操作**：在手機或平板上，長按任一行程卡片 `500ms`。
- **特點**：觸發輕微震動與視覺脈衝動畫，卡片自動進入選取狀態並開啟「多選模式」，後續點擊即可連續勾選其他行程。

### 方案五：智慧同類/同名連鎖選取 (Smart Connected Selection)
- **操作**：在行程卡片的右鍵選單或資訊面板中點擊「選取相似行程」：
  - `選取所有「開會」類型`
  - `選取所有相同標題`
  - `選取所有相同顏色`
- **特點**：一鍵高亮並選取全月曆中符合條件的所有行程，極大提升批次分類管理效率。

### 方案六：日期格/週欄標頭「全選當天/全選當週」 (Header Select)
- **操作**：在展開的日期欄頂部顯示 `[☑ 選取本日行程]` 按鈕，或在星期標頭顯示 `[☑ 選取本週行程]`。
- **特點**：一鍵選取該日期格內的所有行程，無須逐一抽取。

### 方案七：時間範圍選取條 (Time-Range Slider)
- **操作**：在表單或時間軸旁提供時間範圍選擇器（例如設定：`09:00 ~ 12:00`）。
- **特點**：系統自動篩選並選取落在此時間範圍內的所有行程，適用於批次調整早晨或下午的時段行程。

### 方案八：獨立清單視圖與 Checkbox 抽屜 (Batch List View Drawer)
- **操作**：點擊表單中的「📋 行程清單管理」按鈕，展開彈出式/側邊抽屜清單。
- **特點**：以列表形式展示所有行程，帶有 Checkbox 核取框、搜尋過濾關鍵字、排序與 [全選/反選] 功能，適合處理大量行程。

## 🎨 批次編輯表單 (Batch Edit Panel) 動態轉換

當系統偵測到**選取行程數量 >= 2 個**時，右側編輯面板自動切換為 **「批次編輯模式 (Batch Edit Mode)」**：

### 1. 表單頂部提示
- 顯示：`已選取 N 個行程`，並提供 `[取消全選]` 按鈕。

### 2. 欄位更新開關 (僅更新勾選欄位)
為避免誤覆寫其他屬性，每個批次編輯欄位旁皆附有啟用核取框：
- `[☑] 統一修改行程類型` -> 下拉選單選取新類型
- `[☑] 統一修改行程標題` -> 輸入新標題（或使用範本）
- `[☑] 時間整體順延/平移` -> 選取平移時間（如 `+30分鐘`, `+1小時`, `-30分鐘`）
- `[☑] 統一修改顏色` -> 文字顏色 / 背景顏色 / 邊框顏色
- `[☑] 批次刪除行程` -> 刪除所有已選取的行程

## ⚙️ 後端 API 與 Ctrl + Z 復原機制

### 1. 後端批次 API (`api_batch_edit_events.php`)
- **請求格式 (JSON POST)**：
```json
{
    "ids": [12, 15, 18],
    "fields": {
        "type": "團隊會議",
        "color": "#ffffff",
        "background_color": "#2563eb"
    }
}
```
- **PDO 預處理 SQL 語句**：
```php
$inPlaceholders = implode(',', array_fill(0, count($ids), '?'));
$params = array_merge(array_values($fields), $ids);
$sql = "UPDATE events SET " . implode('=?, ', array_keys($fields)) . "=? WHERE id IN ($inPlaceholders) AND deleted_at IS NULL";
```

### 2. Ctrl + Z 復原歷史紀錄整合 (Undo Stack)
- 執行批次修改時，系統自動打包所有受影響行程的原始快照：
```javascript
undoStack.push({
    type: 'BATCH_EDIT',
    records: [
        { id: 12, prev: { date: '2026-07-28', start: '09:00', end: '10:00', color: '#000', bgColor: '#fff' } },
        { id: 15, prev: { date: '2026-07-28', start: '10:30', end: '11:30', color: '#000', bgColor: '#fff' } },
        { id: 18, prev: { date: '2026-07-29', start: '14:00', end: '15:00', color: '#000', bgColor: '#fff' } }
    ]
});
```
- 按下 `Ctrl + Z` 時，遍歷 `records` 一鍵恢復所有卡片的顏色、屬性、位置與標籤。

## 📅 開發階段與建議步驟

1. **第一階段 (多選機制實作)**：優先完成 `Ctrl+點擊`、`☑ 多選模式開關` 與 `手機長按 500ms` 複選機制。
2. **第二階段 (批次表單 UI)**：完成選取 >= 2 時表單自動轉換為「批次編輯面板」與「僅更新勾選欄位」功能。
3. **第三階段 (智慧選取與 API 串接)**：開發 `方案五 (同類選取)`、`api_batch_edit_events.php` 與 `Ctrl+Z` 批次復原。
